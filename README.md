# 💳 Dijital Bankacılık Uygulaması

Kullanıcıların banka hesaplarını yönetebileceği, para transferi yapabileceği, kredi çekebileceği ve döviz/altın işlemleri gerçekleştirebileceği modern bir dijital bankacılık uygulaması.

---

## 🚀 Özellikler

- 🔐 Hesap bilgilerini görüntüleme (TL ve döviz hesapları)
- 💳 Kart bilgilerini inceleme, borç ve bakiye takibi
- 💸 Para transferi (kendi hesabına ve diğer kullanıcılara)
- 🧾 Jredi kartı borcu ödeme
- 🏦 Kredi başvurusu ve kredi limiti üzerinden işlem
- 🌍 Döviz ve altın alım/satım işlemleri

---

## 🛠️ Kullanılan Teknolojiler

| Katman       | Teknoloji        | Açıklama                                                        |
|--------------|------------------|------------------------------------------------------------------|
| Arayüz (UI)  | TROBJECT         | Kullanıcı dostu ve modern arayüz tasarımı                       |
| Veritabanı   | MySQL            | Hesap, işlem ve kullanıcı verilerinin saklanması                |
| API          | Node.js          | İş mantığı ve veri alışverişi için hızlı ve güvenli sunucu katmanı |
